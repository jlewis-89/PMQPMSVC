Phase 1 MVP Kickoff

Goal: Establish a concrete, runnable MVP branch with a detailed sprint plan for Phase 1 deliverables across backend, frontend, and sync adaptor.

Structure:
- backlog.json: MVP task backlog (JSON)
- backlog.md: human-readable backlog outline
- plan.md: sprint cadence, acceptance criteria, and roles
- docs/: MVP-specific design notes and API contracts references

How to use:
- Use backlog.json as the single source of truth for MVP tasks
- Update plan.md as decisions evolve during implementation
- Sync adaptor: Google Drive starter; extendable to other providers
- PMQ templates: per-user customization, stored in user profile

Owner: product/tech lead; collaborators: frontend, backend, sync-adapter engineers
